# Mi Portfolio Web

Portfolio personal de **Alejo Ezequiel Rodriguez**, estudiante de programación de Tandil, Buenos Aires.

**Ver la página:** https://a7alejo.github.io/portfolio/

## Sobre el diseño

Elegí una estética moderna con una grilla tipo "bento": bloques de distintos tamaños y colores vivos (violeta, rosa y amarillo limón), tipografía grande y una barra de navegación flotante. Con JavaScript agregué un botón para cambiar entre modo claro y oscuro, que recuerda la elección, y un reloj en vivo con la hora de Tandil.

## Secciones

- **Sobre mí:** presentación, tecnologías que uso y dónde estoy.
- **Proyectos:** SOP (Proyecto Final) y Floxer.
- **Contacto:** email y GitHub.

## Archivos

- `index.html`: estructura de la página.
- `style.css`: estilos, modo oscuro y diseño adaptable a celulares.

Hecho con HTML, CSS y JavaScript, publicado con GitHub Pages.
